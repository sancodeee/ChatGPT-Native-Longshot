This repository was restored from a complete existing copy of ChatGPT Native Longshot 2.3.3. The recovered material contained 19 runtime files, the original usage guide, an icon guide, and an icon generator. It did not include Git history or the test directory referenced by the original guide.

On 2026-11-11, the project author confirmed that the entire project is their original work, including version 2.0.0, the project source code, and the accompanying custom assets. The reference to modifying version 2.0.0 describes iteration on the same author's work, rather than development based on another author's extension. Ownership is recorded according to that confirmation; obtaining authorization from another upstream project is no longer a pending publication item.

The recovered guide states that the original README declared the MIT license, but the recovered copy did not include the original `LICENSE` or copyright notice. This repository retains that historical statement. A formal license text and copyright attribution remain to be specified by the author; the originality confirmation does not itself serve as a license file.

The initial repository preparation changed layout, development tools, and documentation only. At that point, runtime files in `extension/` were byte-for-byte identical to the recovered 2.3.3 copy. See `CHANGELOG.md` for subsequent changes.
