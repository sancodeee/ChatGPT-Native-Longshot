ChatGPT Native Longshot

Privacy Policy

Publisher: sancodeee Last updated: 2026-11-11

This policy explains how ChatGPT Native Longshot handles data when you use the extension, and how you can control and delete that data.

Conversations and screenshots are processed in your browser and are not uploaded to developer servers.

Image previews may contact original image sources. Your chosen background settings are stored locally. Conversations and images may contain personal or sensitive information; local processing still involves handling that information.

Scope Data handled Image requests Retention and deletion Limited Use Contact

1. Scope and single purpose

The extension lets you select messages from a ChatGPT conversation, generate a long PNG screenshot in the original page appearance, and save it locally or copy it as an image. Data is handled only for message selection, previews, screenshot composition, background settings and export.

ChatGPT Native Longshot is independently developed by sancodeee and is not affiliated with or endorsed by OpenAI. This policy describes the extension itself. The policies of ChatGPT, image source services, GitHub and your email service also apply when you use those services.

2. Data handled and its purpose

Current page and conversation content
When you open the extension or click refresh, it reads the current tab address and up to the latest 50 messages already present in the page DOM, including related text, roles, code, tables, formulas, images and styles, to provide selection and previews. It does not automatically load earlier conversation history that is not displayed. During export, it captures visible pixels of the current conversation page, then crops and composes the selected content in your browser.
Your selected background image
To create a custom export background, the extension reads the PNG, JPEG or WebP file you select and locally resizes and converts it to JPEG. The converted image, original filename and blur setting are saved in the extension's local storage, chrome.storage.local, in the current browser for future use. The extension does not use chrome.storage.sync cloud synchronization.
Exported images and the clipboard
Only when you click save or copy does the extension pass the generated PNG to the browser for download or write it to the system clipboard. The extension does not read the clipboard.
Personal or sensitive information within content
Conversations, screenshots and background images may include names, contact details, private communications, health, financial or location information that you enter or select. The extension does not separately extract these details or build user profiles, but processes them locally as part of that content.

3. Image previews and network requests

Web content, conversations, screenshots and background images are processed and composed in your browser, without transmission to developer servers. The extension has no developer-operated screenshot upload service.

To display conversation images or citation icons, previews may request resources from their original image sources. Failed image reads may also be retried through the extension's background process. These requests send the original image URL, which may include signed or access parameters, and ordinary network information such as your IP address and request headers to the relevant source. They may include that source's cookies or existing credentials where browser rules allow. The extension does not use the Cookies API to read cookies or ask you to provide a password.

The extension is therefore not a fully offline tool. Image sources handle these requests under their own service policies. The extension does not additionally upload conversation text or generated screenshots to those sources.

4. Analytics, advertising, accounts and browsing history

The extension includes no analytics, advertising or third-party trackers, and has no separate account or registration system. It does not read the browsing history API or track activity across websites. The current conversation address and image source addresses are used only to identify supported pages and provide the corresponding capture and preview features.

5. Retention, deletion and your controls

  • Conversations, previews and screenshots: These are temporarily held in browser memory, without being saved as history in persistent extension storage. Close the popup and refresh or close the relevant conversation page to clear the corresponding temporary runtime data.
  • Background image: This remains in local storage until you replace it, select “Restore solid color” or remove the extension. Restoring solid color deletes the saved background image and its filename; the blur setting remains saved.
  • All extension settings: Removing the extension clears its local extension storage in the current browser profile, including the saved background image and blur setting.
  • Saved PNG files and the clipboard: These are managed by you, your browser and your operating system. Restoring solid color or removing the extension does not delete downloaded images or clear the system clipboard. Manage them through your file manager and system controls.

You can export only selected messages, use no background image, or stop using and remove the extension. Check an image before saving or sharing it to make sure it contains only information you intend to disclose.

6. Use, sharing and Limited Use commitment

The extension's use of user data, including information received through Chrome or Google APIs, complies with the Chrome Web Store User Data Policy and its Limited Use requirements. Data is used only for the capture features described here. We do not sell data or provide it to advertisers or data brokers, or use it for unrelated purposes, advertising targeting, profiling, creditworthiness or lending decisions.

The extension does not provide conversations or screenshots to the developer or others for human review. If you voluntarily submit specific content for support, the developer reads it only as needed to address that feedback. Apart from the original-image requests described here and your own decisions to save, copy or submit feedback, the extension does not transmit conversations or screenshots to the developer or other third parties.

Local processing still requires clear disclosure. See the Chrome Web Store User Data Policy FAQ for the relevant requirements.

7. This website and voluntary feedback

The project website and privacy pages contain no analytics tools, advertising, third-party fonts or scripts. The website is hosted on GitHub Pages. GitHub logs visitor IP addresses for security purposes, as explained in the GitHub Pages data collection notice and GitHub Privacy Statement.

If you contact us by email or GitHub, the service you choose processes the email address, account information and message content you submit. The developer uses the information you provide to reply and investigate the issue. The extension does not automatically submit feedback or attach conversations. GitHub Issues are public; do not submit private conversations, credentials or other sensitive information there.

8. Policy updates

If data handling changes, we will update this page and its last-updated date, and describe the changes in the relevant project release notes.
