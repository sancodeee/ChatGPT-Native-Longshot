隐私政策

发布者：sancodeee 最后更新：2026-11-11

本政策说明「ChatGPT 原样长截图」如何处理你使用扩展时涉及的数据，以及你如何控制和删除这些数据。

对话与截图在浏览器内处理，不上传到开发者服务器。

图片预览可能访问原图片来源；自选背景设置保存在本机。对话或图片可能包含个人及敏感信息，本政策不将本机处理等同于“不处理个人信息”。

适用范围 处理的数据 图片与网络请求 保留与删除 有限使用 联系

1. 适用范围与单一用途

本扩展的用途是：让你选择 ChatGPT 对话中的消息，按原页面外观生成 PNG 长截图，并保存到本机或复制为图片。数据处理仅用于消息选择、预览、截图合成、背景设置与导出。

本扩展由 sancodeee 独立开发，与 OpenAI 无隶属关系或官方背书。本政策说明扩展自身的行为；你使用 ChatGPT、图片来源服务、GitHub 或邮件服务时，也适用对应服务的政策。

2. 处理哪些数据，以及为什么

当前页面与对话内容
当你主动打开扩展或点击刷新时，扩展读取当前标签页地址及当前页面 DOM 中已显示的最近最多 50 条消息，包括相关文字、角色、代码、表格、公式、图片和样式，用于选择及预览。扩展不会自动加载未显示的历史对话。导出时会读取当前会话页面的可见像素，在浏览器内裁切、拼接所选内容。
你选择的背景图片
为生成自定义导出背景，扩展读取你选择的 PNG、JPEG 或 WebP 文件，在本机缩放并转换为 JPEG。转换后的图片、原文件名和背景模糊度会保存在当前浏览器的扩展本机存储 chrome.storage.local，以便下次使用。扩展不使用 chrome.storage.sync 云同步。
导出图片与剪贴板
只有你点击保存或复制时，扩展才将生成的 PNG 交给浏览器下载，或写入系统剪贴板。扩展不读取剪贴板。
可能包含的个人或敏感信息
对话、截图和背景图可能包含你输入或选择的姓名、联系方式、私人通信、健康、财务、位置等信息。扩展不单独提取这些信息或建立用户档案，但会随相应内容在本机处理它们。

3. 图片预览与网络请求

网页内容、对话、截图和背景图片的处理与合成在浏览器内完成，不发送到开发者服务器。扩展没有开发者提供的截图上传服务。

为显示会话中的图片或引用图标，预览可能向它们的原图片来源请求资源；图片读取失败时也可能通过扩展后台重试。这些请求会把原图片 URL（可能含签名或访问参数）及 IP 地址、请求头等常规网络信息发送给相应来源，并可能附带浏览器规则允许的该来源 Cookie 或已有凭据。扩展不使用 Cookie API 主动读取 Cookie，也不要求你提供密码。

因此，扩展并非完全离线工具。原图片来源按照其服务规则处理收到的请求；扩展不会另行把对话正文或生成的截图上传给这些来源。

4. 分析、广告、账户与浏览历史

扩展不包含分析统计、广告或第三方跟踪器，没有独立账户或注册系统。不读取浏览历史 API，也不进行跨网站活动跟踪。当前会话地址和图片来源地址仅用于识别支持的页面及完成相应截图、预览功能。

5. 保留、删除与用户控制

  • 对话、预览与截图：只在浏览器运行内存中暂存，不作为历史记录写入扩展持久存储。关闭弹窗并刷新或关闭相关会话页面，可清除相应的临时运行数据。
  • 背景图片：会持续保存在本机，直至你替换图片、点击「恢复纯色」或移除扩展。「恢复纯色」会删除保存的背景图片及其文件名，模糊度设置仍会保留。
  • 全部扩展设置：移除扩展会清理其在当前浏览器配置中的扩展本机存储，包括保存的背景图和模糊度。
  • 已保存的 PNG 与剪贴板：由你、浏览器和操作系统管理。恢复纯色或移除扩展不会删除已下载的图片，也不负责清除系统剪贴板；请通过文件管理器和系统提供的方式自行管理。

你可以选择只导出部分消息、不设置背景图，或停止使用并移除扩展。保存和分享前，请确认图片没有包含你不希望公开的信息。

6. 数据使用、分享与有限使用承诺

本扩展对用户数据的使用，包括通过 Chrome 或 Google API 获取的信息，遵守 Chrome Web Store 用户数据政策的有限使用（Limited Use）要求。我们仅为本政策说明的截图功能处理数据，不将用户数据出售或转交广告商、数据经纪商，不用于无关用途、广告定向或画像，也不用于信用评估或借贷决策。

扩展不会把对话和截图提供给开发者或其他人员人工查看。你主动向支持渠道提交特定内容时，开发者仅在处理该反馈所需的范围内阅读你提供的信息。除本政策说明的原图片来源请求及你主动保存、复制或提交反馈外，扩展不向开发者或其他第三方传输对话和截图。

即使数据只在本机处理，也属于需要说明的数据处理。相关要求可参阅 Chrome Web Store 用户数据政策 FAQ。

7. 本网站与主动反馈

项目网站和隐私页不嵌入分析工具、广告、第三方字体或脚本。网站由 GitHub Pages 托管；GitHub 会为安全目的记录访问者 IP 地址，详见 GitHub Pages 数据收集说明及 GitHub 隐私声明。

如果你通过邮箱或 GitHub 主动反馈，所选服务会处理你提交的邮件地址、账号及消息内容，开发者会使用你提供的信息回复和排查问题。扩展不会自动提交反馈或附加对话。GitHub Issues 为公开渠道，请勿提交私人对话、凭据或其他敏感信息。

8. 政策更新

数据处理方式发生变化时，我们会更新本页面及顶部的最后更新日期，并在相关版本的项目更新说明中披露变化。
