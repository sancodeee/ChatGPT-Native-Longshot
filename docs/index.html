将选中的 ChatGPT 对话导出为 PNG，保留原会话的字体、主题、代码、表格、公式与图片。保存到本机，或复制到剪贴板。

免费使用 · Chrome Web Store 发布准备中。源码、当前安装方式和更新说明见项目仓库。

按需要选择

勾选全部或部分消息，不连续的消息也会按对话顺序拼接。无需把整段会话都放进图片。

保留页面外观

保留原页面的深浅主题与内容排版，支持 1×、2×、3× 导出倍率，以及 PNG 保存和图片复制。

自己的背景

选择 PNG、JPEG 或 WebP 图片，调整背景模糊程度。背景设置保存在当前浏览器，供以后导出使用。

从对话到长图，只需几步

  1. 打开 ChatGPT 对话，等待回复和图片加载完成，然后点击扩展图标。
  2. 选择消息和导出倍率。需要背景图时，进入背景设置页选择图片并等待保存完成。
  3. 点击保存或复制。截图期间保持对话标签页不变，避免滚动、切换标签页或调整窗口。

扩展读取当前页面已显示的最近最多 50 条消息，不会自动加载全部历史记录。超长导出受浏览器图片尺寸限制，必要时请减少消息或降低倍率。ChatGPT 页面更新可能影响兼容性。

知道内容在哪里处理

对话预览与截图在浏览器内处理，不上传到开发者服务器。扩展没有分析统计、广告或独立账户系统，也不读取浏览历史 API。

图片预览可能向原图片来源请求资源；背景图及模糊度会保存在本机。对话可能包含你输入的个人或敏感信息，请在分享前检查导出内容。
