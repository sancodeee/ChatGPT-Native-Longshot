# ChatGPT 原样长截图

**简体中文** · [English](README.en.md)

将选中的 ChatGPT 消息导出为 PNG 长截图，保留原会话的字体、主题、代码、表格、公式与图片。支持保存图片、复制图片，以及自定义图片背景和模糊效果。

当前扩展版本：**2.3.3**。采用 Manifest V3、原生 JavaScript 和浏览器截图，无需构建即可加载。

## 功能

- 勾选全部或部分消息，按对话顺序导出；不连续的消息自动拼接。
- 保留原页面深浅主题与渲染外观，支持 1×、2×、3× 导出。
- 展开代码块的内部滚动区域，长行折行，减少代码截断。
- 自定义 PNG、JPEG、WebP 背景图，支持 0–32px 模糊；设置保存在本机。
- 导出四周保留随倍率缩放的 32px 留白，导出后恢复页面与滚动位置。
- 内置简体中文、繁体中文、英语、德语、西班牙语、法语、日语界面；缺失翻译回退到英语。
- Apple 风格的浅色弹窗，使用系统字体、分段筛选和清晰的主次操作，支持键盘焦点及减少动态效果偏好。

## 安装

1. 克隆或下载本仓库。
2. 在 Chrome 或兼容的 Chromium 浏览器中打开 `chrome://extensions/`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择仓库内的 **`extension/` 目录**，该目录下直接包含 `manifest.json`。
4. 刷新已经打开的 ChatGPT 对话页面，点击扩展图标。

已有旧版扩展时，先停用旧版，避免同时加载两个版本。安装后请保留加载的目录；修改源码后，在扩展管理页点击「重新加载」，再刷新对话页面。

如果使用打包 ZIP，请先解压，直接加载解压后包含 `manifest.json` 的目录。仓库根目录和 `dist/` 目录都不是可加载的扩展根目录。

## 使用

1. 打开 `https://chatgpt.com/` 中的对话，等待回复和图片加载完成。
2. 调整主题、窗口宽度与浏览器缩放，点击扩展图标。
3. 勾选消息并选择导出倍率；新消息出现后，可点击「刷新对话」。
4. 按需选择图片背景与模糊度，再点击「保存」或「复制」。

截图期间保持对话标签页处于当前状态，避免滚动、切换标签页或调整窗口。背景图设置会在以后导出时自动沿用，也可以恢复纯色背景。

## 开发与打包

加载和使用扩展不需要 Node.js、Python 或安装依赖。运行维护工具需要 **Node.js 22+、Python 3.9+**，检查与打包只使用标准库。

在仓库根目录执行：

```bash
# 检查清单、文件引用、语言资源、图标尺寸及脚本语法
python3 scripts/check.py

# 先检查，再生成安装 ZIP
python3 scripts/package.py
```

输出文件为 `dist/ChatGPT-Native-Longshot-2.3.3.zip`，ZIP 根目录直接包含 `manifest.json`。版本号由扩展清单读取，文档、开发工具和本机文件不会打入安装包；`dist/` 不纳入 Git。

维护流程、模块职责、权限用途和手工回归清单见 [开发指南](docs/DEVELOPMENT.md)。图标重新生成是可选操作，见 [图标说明](docs/ICONS.md)。

## 限制与数据处理

- 读取当前页面 DOM 中最后 50 条消息，不会自动加载未显示的历史记录。
- 输出单边不超过 30,000 像素、总面积不超过 6,400 万像素；超出时请减少消息或降低倍率。
- 高倍率不会增加原屏幕图像中不存在的细节；会话越长，滚动截图所需时间越长。
- 图片背景模式每段需要明暗两次原生截图，比纯色模式耗时更长。
- 背景图支持 PNG、JPEG、WebP，最大 20MB；保存时转换为 JPEG，最长边缩至不超过 1600px。
- 截图在本机生成；背景图与模糊度保存在 `chrome.storage.local`，不使用云同步。预览可能向原图片地址请求图片，不另设截图上传服务。
- ChatGPT 页面结构更新可能影响消息识别和截图，需要在真实对话中回归验证。

## 验证范围

自动检查验证的是项目结构、资源引用、脚本语法和安装包生成，不能替代真实对话中的保存、复制与页面恢复验证。恢复的源码副本没有包含旧说明中提到的历史测试文件，本仓库不会将其列为现有测试能力。
